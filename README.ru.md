# ЛЕЗВИЕ · лендинг барбершопа

**Одностраничник для барбершопа в Ижевске, сделан как благодарность моему барберу.**

*[Read in English →](README.md)*

Живой сайт: **https://lezvie-dvizhenie.netlify.app**

Статика на HTML/CSS/JS: без фреймворка, без бэкенда, без базы. Редакционный
дизайн, анимации при прокрутке, параллакс, акцент терракота/золото.

## Локальный запуск

```bash
npm run dev   # → http://localhost:3003
```

## Управление контентом

**Без админки и логинов, так задумано.** Контент (фото галереи, отзывы) лежит в
JS-массивах и обновляется правкой кода с последующим деплоем:

- `js/gallery.js`: список фотографий галереи
- `js/reviews.js`: избранные отзывы с 2ГИС (ротация без повторов)

## Деплой

**Через Netlify CLI, не по пушу.** Один `git push` живой сайт не обновляет.

```bash
netlify deploy --prod --dir=. --site=a63d409a-6a40-451c-a279-c1357487ec0c
```

## Структура

- `index.html`, `css/`, `js/`, `img/`: сам сайт
- `Barbers/`, `Videos/`: исходные фото и видео, пока не подключены к сайту
- `tasks/`: рабочие заметки, передача между сессиями (`HANDOFF.md`)
